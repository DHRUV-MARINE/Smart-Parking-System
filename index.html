Why SmartParking

Real algorithms, not just a pretty page

The search, sorting, routing and availability logic all run in C++ — the interface is just a window into it.

Shortest road distance

A weighted graph of roads, landmarks and parking entrances, solved with Dijkstra and a hand-written binary min-heap. O((V+E) log V)

Cheapest and nearest rankings

Merge sort for distance and availability, quick sort for price, and binary search over a name index. All implemented from scratch.

Slots that stay in sync

Each slot lives in a linked list, bookings in a second one, and a full lot has a FIFO waiting queue. Book or cancel and availability updates instantly.

How it works
